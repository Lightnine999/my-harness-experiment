# traces — 수정 전후의 실행 기록

| 폴더·파일 | 내용 |
|---|---|
| `before/` | **수정 전** (A, 훅 없음) 6회 — T1 키 문제 3회, T2 정책 문제 3회 |
| `after/` | **수정 후** (B, `SessionStart` 훅) 6회 — T1 3회, T2 3회 |
| `pilot/` | 시범 실행 1회 (A·T1, AGENTS.md 그대로). 천장 효과 규칙을 발동시킨 실행 |
| `RUN-LOG.md` | 점검, 시범, 본 실행 순서대로 남긴 기록과 관찰 |
| `results.json` | 조건·과업별 집계와 판정 |
| `judgments.json` | 최종 답을 읽고 사람이 판정한 "첫 원인" 12건 |

## 각 실행 파일에 담긴 것

1. 조건, 과업, 모델, 턴·도구 호출 수, 변경 파일
2. 요청 문장
3. (B만) `SessionStart` 훅이 넣은 출력
4. 도구 호출 순서 — 입력 전체와 결과 앞부분 600자
5. 최종 답 전체
6. 코드·마이그레이션을 고쳤다면 그 `git diff`

## 원본에서 바꾼 것

`fixture/scripts/export_traces.py`로 `claude --output-format stream-json` 원본을 옮겼습니다. 옮길 때 아래를 지웠습니다.

- 가짜 키 전체 값과 판정용 조각, `BACKEND_SECRET` → `<가짜키-삭제>`
- 시행 사본 경로 → `<사본>`, 홈 경로 → `~`

옮긴 뒤 전체 파일에서 지운 값을 다시 검색해 0건인 것을 확인했습니다. 원본 JSON은 공개하지 않습니다.
