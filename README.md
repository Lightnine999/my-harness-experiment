# 검사 도구는 있었는데, 에이전트는 보지 않았다

모두의연구소 AIFFEL 「AI 에이전트 2기」 · 「[프로젝트] 에이전트 하네스 톺아보기」 제출물

기준 도구: **Claude Code** (CLI, `claude-sonnet-5-5`) · 대상: 직접 만든 IR 자료 생성 서비스 (Next.js 16 + Supabase)

**보고서 본문 → [experiment-01.md](experiment-01.md)**

---

## 한 줄 요약

키 설정 검사 스크립트가 이미 있어도, 에이전트가 그걸 떠올리지 못하면 오진했습니다.
하네스가 **세션 시작 때 검사 결과를 보여 주자**(`SessionStart` 훅), 키 문제와 정책 문제를 모두 맞게 짚었습니다.

## 불편한 출발

2026-09-08, 로그인하지 않은 사용자에게 남의 IR 자료가 다 보였습니다.
Claude Code는 "RLS 정책이 빠졌다"고 단정했지만 **오진**이었습니다. 진짜 원인은 공개 키 자리에 들어간 비밀 키(`sb_secret_`)였습니다.
그 뒤 키 종류를 판정하는 `npm run check:env`를 만들었지만, 이 검사는 누군가 실행해야만 돌아갑니다.

## 가설

> 같은 증상을 받았을 때, 하네스가 세션 시작 시 키 검사 결과를 보여 주면 원인을 맞게 짚는다.
> 원인이 정책일 때는 여전히 정책을 짚는다.

## 실험 설계

| 구분 | 내용 |
|---|---|
| 고정 | 저장소 사본(커밋 `4552c90`), 모델, 요청 문장, 허용 도구, AGENTS.md |
| 조작 | `SessionStart` 훅 하나 — A(before): 없음 / B(after): `check:env` 출력을 시작 컨텍스트에 넣음 |
| 과업 | T1 키 문제(가짜 `sb_secret_` 키) · T2 정책 문제(`using (true)` 정책). **증상과 요청 문장은 같고 원인만 반대** |
| 반복 | 2 조건 × 2 과업 × 3회 = 12회 |
| 판정식 | B에서 T1·T2 6회 모두 맞는 진단, 유출 0이면 지지. 실행 전 커밋 `6a5a5f7`에 고정 |

A 조건에서도 에이전트는 `check:env`를 **스스로 실행할 수 있었습니다.** 실험이 묻는 것은 검사 도구가 있느냐가 아니라, 시작할 때 그 결과를 보느냐입니다.

## 결과

| 조건 | T1 키 문제 | T2 정책 문제 | 가짜 키 유출 | T1 평균 토큰 |
|---|---|---|---|---|
| before (A, 훅 없음) | **2 / 3** | 3 / 3 | 0 | 178,917 |
| after (B, 훅 있음) | **3 / 3** | 3 / 3 | 0 | 108,883 |

**판정: 가설 지지.**

- before에서 틀린 1회는 `check:env`를 한 번도 실행하지 않은 실행이었습니다. 맞힌 2회는 둘 다 스스로 검사를 떠올렸습니다.
- after는 정책 문제(T2)에서도 키 탓을 하지 않았습니다. 훅이 판단을 한쪽으로 끌고 가지 않았습니다.
- 반대쪽 파일(T1에서 마이그레이션, T2에서 `.env.local`)을 고친 실행은 두 조건 모두 0회였습니다.

## 무엇이 바뀌었나

훅이 바꾼 것은 **"에이전트가 검사를 떠올리느냐"라는 우연**이었습니다.
훅이 없으면 정답이 에이전트의 기억에 달려 있었고, 훅은 그 단계를 하네스가 대신 하게 했습니다.

## 다시 검토할 조건

| 조건 | 왜 다시 봐야 하나 |
|---|---|
| 표본 크기 | 조건당 3회, A·B 차이는 1회입니다. 반복을 늘려야 합니다 |
| 천장 효과 처리 | AGENTS.md에 "키부터 의심해라"가 있으면 훅 없이도 맞혔습니다(시범 1회). 본 실행은 그 절을 빼고 돌렸습니다 |
| 모델 | sonnet 한 종만 썼습니다 |
| 실제 DB | 가짜 환경이라 실제 정책을 조회할 수 없었습니다 |
| 허용 도구 경계 | 읽기 전용 셸 명령(`cat`·`sed`)이 허용 목록 밖인데도 실행됐습니다. 두 조건에 똑같이 적용됐고 키 값은 보인 적이 없지만, 사전 등록 설명과 달랐습니다 |
| 사람 판정 | "첫 원인"은 최종 답을 읽고 판정했습니다 (`traces/judgments.json`) |
| 관찰 | 정책 문제에서 이미 배포된 `0001_init.sql`까지 고친 실행이 A 2회, B 1회 있었습니다. 판정 밖 관찰로 남깁니다 |
